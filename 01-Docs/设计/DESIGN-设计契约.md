# 设计契约 · 知树 KnowTree

## 目标

面向长期积累的独立研究者、工程师与学生，提供一款「丢进去就长在树上」的个人知识储备工具。核心任务只有一条：把散落在 PDF、网页、聊天里的片段以最低成本收进来，系统自动归类并挂在知识树上，之后按遗忘曲线送回眼前。原型用于验证导航结构、收录流程与状态流转，不追求业务完整。

## 视觉方向

暗色底 + 单一暖金点缀（#C9A96B），大面积留白与低对比描边，让内容本身发光。标志性元素是「可点的知识树」：细金枝干连接圆环节点，节点半径与亮度随知识量微调，节点本身是导航入口而不是装饰插画。卡片一律用模板生成，不用 AI 插画；吉祥物只出现在「我的」，不进入主路径。

## 设计令牌（Token）

颜色：底 #0A0A0B，面 #141416，面-2 #1B1B1E，描边 rgba(255,255,255,.08)，主文 #F4F1EA，次文 #A6A199，弱文 #6E6A63，点缀 #C9A96B，待确认 #D8A657，成功 #82A98C，危险 #C97A66。
字体：系统中文栈（PingFang SC / Noto Sans SC），标题 500 字重、正文 400，大标题 300；数字使用 tabular-nums。
间距：4pt 基准，页面边距 20px，卡片内边距 14–16px，卡片间距 10px。
圆角：小 10、中 14、大 20、胶囊 999。
层级：不用阴影分层，只用 1px 描边与表面色差；仅主按钮与回溯卡片带金色外发光。

## 共享壳层

全屏应用壳，最大宽度 430px 居中；顶部为标题区（标题 + 统计 + 搜索入口），底部为三项 Tab（知识树 / 知识库 / 我的）。详情、回溯、收录页不显示 Tab，使用返回或取消。所有页面共用 theme.css 与 app.js，数据存于 localStorage，跨页保持状态。桌面端仅做居中呈现，不模拟手机外框。

## 页面

- `tree`（index.html）：知识树首页，节点可点，待确认横幅，丢一条入口。
- `library`（library.html）：知识库列表，全部 / 待确认 / 收藏三种筛选，行点开详情。
- `search`（search.html）：搜索页，实时过滤标题、摘要、标签与正文。
- `inbox`（inbox.html）：待确认收件箱，逐条确认归类、处理疑似重复。
- `card`（card.html）：卡片详情，收藏、改节点、互链跳转。
- `node`（node.html）：单节点视图，该节点下的全部卡片。
- `review`（review.html）：每日回溯，记得 / 忘了，三张结束。
- `compose`（compose.html）：收录页，粘贴即入库，模拟解析后进入待确认。
- `me`（me.html）：我的，统计、数据主权、演示数据重置。

## 状态与交互

状态：收录后为「解析中」（loading），1.2 秒后进入「待确认」；确认后入树；疑似重复可合并或保留；列表为空时显示 empty；回溯三张看完显示 complete。
关键关系：Tab 用 `aria-current="page"`；筛选器用 `aria-selected` + `aria-controls`；收录与确认均给出 toast 反馈并支持撤销。
稳定锚点：`tree.compose`、`tree.inbox-banner`、`inbox.accept`、`inbox.merge`、`library.filter`、`card.favorite`、`review.recall`、`compose.submit`。
