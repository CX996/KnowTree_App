产品概念方案 · v0.3

知树 KnowTree

一个长期、简约的个人知识储备软件 —— 把总结「丢」进去，它自动归类、挂上知识树、去重合并、建立互链、生成精美卡片，并告诉你下一步该往哪深入。
只做核心闭环，绝对不加法。

移动端 App 个人云端 · 多端同步 AI 自动归类 · 去重 · 互链 简约精美卡片
一句话定位：「知识随手丢，树自会长大。」你负责记录，它负责把零散知识整理成一条理清晰、彼此互联的个人知识树，并用卡片与回溯让你真的把知识留下来。

01先看懂它在解决什么

用你提到的真实例子走一遍，理解它的核心价值。

🤖

你了解了一个算法

今天研究「机器人的一种标定算法」，在学习时认真写了一篇总结笔记。

📥

把总结「丢」进去

在 App 里粘贴文字，或直接导入一段 Markdown / Word / PDF 文档。

🌿

自动收编成节点

系统自动归类、去重合并，挂到「机器人 → 标定算法」知识树对应节点下。

🪄

生成精美卡片

自动产出简约卡片，并与已有知识建立互链，日后可顺链探索。

◈ 它到底解决什么痛点

· 零负担记录 —— 不用先想好在哪个分类，随手记录即可，归类交给 AI。

· 长期沉淀不丢失 —— 知识进入个人云端，手机/电脑随时取用，不再是散落的笔记和文档。

· 让知识长成体系 —— 不是一堆扁平笔记，而是一颗能看见生长脉络、彼此互联的知识树。

· 不重复、可串联 —— 重复知识自动合并去重；互链让你能顺着关系探索知识之间的联系。

· 不只是收藏，而是真的用起来 —— 每日回溯 + 深度推荐，避免「收藏了=学会了」。

02功能范围 · 六项核心闭环

坚持「绝对不做加法」——首发只做能形成完整闭环的六件事，其余一律砍掉。

📥

快速收录与文档导入

粘贴文本，或导入 Markdown / Word / PDF / 图片（OCR）。「一丢即收」，无需手动填写任何字段。

🧠

AI 自动归类收编

自动生成标题、一句话摘要、标签；匹配已有知识树节点挂载，没有则自动新建节点。

↻

重复知识自动合并

新知识与已有内容高度相似时，自动识别并提示合并—去重归档，避免知识库越攒越乱。

◈

知识互链

自动发现知识间的关联并建立互链（也可手动），形成可顺链探索的知识关系网。

🌿

知识树与精美卡片

可视化知识树；每条知识生成简约卡片，支持收藏。

⋔

快速检索与深度推荐

关键词 + 语义搜索秒级定位；基于知识库与互链，推荐值得深入的关联节点/主题。

明确「不加」什么

不做社交/分享广场、不做复杂富文本编辑器、不做多人协作、不做冷门格式生态、不做多余设置项。所有精力只押在这六件事能否顺滑跑通。

03一次收录的完整旅程

从「丢进一段总结」到「去重合并、建立互链、生成卡片、推荐深入」，全自动完成。

1

丢入内容

App 内粘贴文本，或导入文档/图片。支持批量，一次可丢多条。

2

解析与提取

后台解析文档正文（PDF/Word/Markdown），图片走 OCR 或直接收录，抽出可读文本。

3

AI 理解与去重检测

LLM 生成标题、摘要、标签；同时用语义相似度检测重复，弹出「合并 / 保留」供确认。

4

自动归类挂树

匹配知识树节点自动挂载；没有则自动新建节点。

5

建立知识互链

基于语义与标签，自动关联 1–3 条相关既有知识并建立互链；也可手动连线。

6

入索引与节点生长

内容写入语义检索索引；知识树对应节点「生长」，吉祥物成长值 +1。

7

推荐深入方向

结合知识库、互链与浏览记录，推荐 1–3 个值得深入的关联主题。

04技术栈选型

围绕「移动端 App + 个人云端多端同步 + AI」选定，尽量复用成熟组件、少造轮子。

前端 · 移动端
  • Expo (React Native) — 一套代码同时出 iOS/Android，轻快、生态成熟。
  • React Navigation — 底部四个 Tab（知识树 / 知识库 / 收藏 / 我的）。
  • 自研简约主题 — 克制的暗色底、单点缀色、圆角卡片，高级不花哨。
后端 · Supabase
  • Postgres — 存知识节点、条目、标签、互链边、收藏、回溯记录。
  • Auth — 邮箱登录，账号体系与多端同步的基础。
  • Storage + Edge Functions — 存原始文档；跑解析、AI 编排与定时推送。
AI · coze-coding-dev-sdk
  • LLM（豆包 / DeepSeek / Kimi） — 归类、摘要、标签、深度推荐。
  • Embedding — 语义检索 RAG、重复检测、互链发现、相关推荐。
  • 文生图（Seedream） — 知识卡片插画、吉祥物形象。
文件解析
  • PDF / Word / Markdown 解析 — 复用 fetch-url 文档解析能力，抽正文。
  • 图片收录 / OCR — 拍照、截图可直接挂载或转文字。
  • 全部走后端 — 客户端零解析负担。

06可玩性设计 · 四项

让「长期沉淀」不枯燥——用成长与回溯让用户愿意持续用下去，同时保持克制。

◈

知识树生长

成就可视化

每次收录新知识，对应节点发光「生长」一截。打开 App 能看到整棵树的蔓延。

↻

每日回溯卡片

对抗遗忘

每天定时推送 1–3 张随机旧卡片，用简单间隔权重避免旧知识沉底。

♡

卡片收藏夹

集邮式沉淀

一键收藏喜欢的知识卡片，形成专属收藏册，逐步丰富。

◆

吉祥物养成

长期陪伴

专属吉祥物随知识积累解锁表情与装扮，越学越有陪伴感。

可玩性的克制原则

所有可玩点都做「轻量」——不引入抽卡充值、不强制社交、不做复杂数值体系。它们只为强化「记录 → 成长 → 回顾」的主循环服务，绝不喧宾夺主。

07实施路线

先小步验证核心闭环，再叠加可玩性与打磨体验。

M0

原型验证 · 打通「丢 → 收编 → 去重 → 互链 → 卡片」

先用轻量原型验证链路能否跑通、看清 AI 归类与去重效果。此阶段不写正式 App。

M1

MVP · 移动端 App

Expo App + Supabase：账号多端同步、六项核心功能、知识树与卡片、吉祥物基础形象、关键词+语义检索、去重与互链。这是「绝对不加法」的正式首发版本。

M2

打磨与体验

离线暂存更完善、更多文档格式、检索与去重准确率、动效与性能。长期愿景：成为真正理解你的个人知识伙伴。

09已确认决策 · 边界清单

以下事项已在评审时逐项确认，作为开发与验收的边界依据。

类别决策项结论
架构树与互链的关系树＋互链并存：树管归类，互链管跨主题关系
一条知识的归属单节点＋多标签，不做多父节点
AI 归类纠偏可手动拖拽/改标签，AI 记住反馈变准
离线使用本地草稿暂存，联网后自动同步收录
数据安全数据主权全做进 MVP：导出(MD/JSON)＋注销彻底删除＋不用于 AI 训练
云端加密常规存储＋隐私声明先行，端到端加密放 M2
多端同步冲突后写覆盖＋保留历史版本
AI 体验重复知识合并弹窗确认「合并/保留」＋可撤销
知识互链建立自动建链＋可手动撤销/补充
检索范围标题＋摘要＋正文＋标签＋OCR
每日回顾算法简单权重（久未看优先）＋「记得/忘了」反馈
运营成本与收费MVP 内测免费，跑通后再议
发布上架顺序Web 原型验证 → Android → iOS(TestFlight)

10最后待定小项

已确认的决策见上一章，以下为剩余可随时拍板的轻量小项。

① 图片的收录方式倾向？

图片既支持 OCR 转文字，也支持把图片本身作为知识卡片挂树。两者都要，还是先做其一？

② 你是否已有 AI 平台云资源/账号？

若已配置豆包 / DeepSeek / 扣子云的密钥可直接接入；没有的话可按开箱即用的默认配置规划。

③ 命名「知树 KnowTree」可否？

App 名称可随时改，这只是工作名。
