# KT-FOX-01 角色制作资料

本目录包含知树国风灵狐的角色制作规格、比例控制图和外部绘图软件提示词。

状态：透明角色主形象已于 2026-11-04 批准，后续界面开发不再反复改设。

## 文件说明

- `knowtree-spirit-fox-production-brief.md`：完整角色规范、动画状态机、Rive 分层、验收标准。
- `knowtree-spirit-fox-character-sheet.html`：四页 A3 角色图纸，可在浏览器中查看和打印。
- `knowtree-spirit-fox-character-sheet.pdf`：已渲染并检查的四页 A3 PDF。
- `kt-fox-01-body-control.svg`：正面、侧面、尾巴和金纹位置的比例控制图。
- `knowtree-spirit-fox-ai-prompts.txt`：可直接复制到外部绘图软件的提示词包。
- `references/kt-fox-01_proportion-anchor-v1.jpeg`：米色底构图与比例参考，不再作为产品贴图。
- `references/kt-fox-01_rimlight-reference-v1.png`：只用于提取右后方暖金轮廓光。
- `references/kt-fox-01_transparent-anchor-v1.png`：2048 × 2048 透明生产母版，产品首选。
- `references/kt-fox-01_transparent-web-v1.png`：512 × 512 透明网页版本。
- `references/kt-fox-01_action-sheet-v1.jpeg`：用户提供的原始六动作设定图。
- `references/motion/`：从动作表拆出的六个透明 PNG 源帧。
- `assets/pet/`：六个 768 px 以内的透明 WebP 网页帧，总计约 182 KB。
- `knowtree-spirit-fox-design-kit-v1.4.zip`：包含以上资料、动作帧和网页资源的完整交付包。

## 使用顺序

1. 以 `transparent-anchor-v1` 作为正式角色生产母版，`transparent-web-v1` 用于网页。
2. 首版界面使用透明主形象和轻量位置、透明度、呼吸、跳跃与探头动作。
3. 不用静态整图伪造四足奔跑，不拉伸四肢和尾巴。
4. 后续需要真实动作资产时，再以该锚点生成侧身、表情和动作关键姿态。
5. 在分层绘图软件中清理，并按规格书的 Rive 层级绑骨。

## 注意事项

- 图纸中的线稿只用于控制比例和位置，不是最终美术。
- 不采用大头、3D 玩偶、拟人狐妖、机械狐或青色霓虹方向。
- 提示词包保留给后续动画资产制作；当前不再生成同质角色图。
- 图 10 只用于界面光影，不参与角色造型修改。
- 角色只能引导和打开流程，不能代替用户写入。
- 所有最终资产必须为原创，不带文字、签名、水印和已有 IP 造型。
